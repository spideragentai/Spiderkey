# SPIDER KEY SYSTEM v12

## نصب / آپگرید
1. از `database/spider.sqlite` بکاپ بگیرید.
2. همه‌ی فایل‌ها را روی سرور آپلود و جایگزین کنید (پوشه‌ی `api/` هم).
3. فایل `config.local.php` با مقادیر فعلی شما پر شده است؛ مقادیر حساس دیگر داخل `config.php` نیستند.
4. بدون ترمینال: `https://دامنه/selfcheck.php?token=WEBHOOK_SECRET` را باز کنید (سینتکس همه‌ی فایل‌ها، افزونه‌ها، دیتابیس و اتصال تلگرام)؛ بعد از اتمام فایل را حذف کنید.
5. وارد `admin.php` → Settings شوید و «Register Telegram webhook» را بزنید.
6. Cron (از cPanel → Cron Jobs، یا سرویس‌هایی مثل cron-job.org با URL):
   - `https://دامنه/cleanup.php?token=WEBHOOK_SECRET` هر ۱۰ دقیقه
   - `https://دامنه/health_cron.php?token=WEBHOOK_SECRET` هر ۳۰ دقیقه

## ⚠️ امنیت (حتماً)
- توکن ربات، رمز ادمین، WEBHOOK_SECRET و API_SECRET داخل فایل zip بودند؛ همه را عوض کنید
  (توکن جدید از @BotFather، رمز ادمین ترجیحاً به‌صورت هش bcrypt در `config.local.php`).
- `SECRET_SALT` را **هرگز** عوض نکنید؛ کلیدهای لایسنس با آن رمز/هش شده‌اند.

## مهم‌ترین رفع باگ‌ها
- `db()`: در هر خطا کل دیتابیس را **حذف** می‌کرد (حتی database is locked) → حالا فقط قرنطینه‌ی فایل خراب.
- پوشه‌ی `database/` و فایل‌های `-wal/-shm` از وب قابل دانلود بودند → بسته شد.
- `health_cron.php` به‌خاطر نبودن `tg_send` خطای fatal می‌داد → `tg.php` مشترک.
- ربات: زمینه‌ی ساخت کلید «آخرین pending سراسری» بود (تداخل بین ادمین‌ها) → داخل callback_data.
- ربات: پیام همگانی در callback_data جا نمی‌شد (حد ۶۴ بایت) → ذخیره در pending.
- ورود پنل نماینده کار نمی‌کرد (تابع doLogin در شاخه‌ی اشتباه بود) + CSRF با چند تب خراب می‌شد.
- `api_docs.php` کلید API محصول را برای همه نشان می‌داد.
- `link.php` رمز ادمین را در URL می‌فرستاد → ریدایرکت به پنل ادمین.
- بکاپ در حالت WAL ممکن بود ناقص باشد → `VACUUM INTO`.
- «آنلاین» اشتباه شمرده می‌شد (نشست‌های تجمعی) → heartbeat در ۱۵ دقیقه‌ی اخیر.
- `status`/`device_info` در API از ستون‌های قدیمی (خالی) می‌خواند.

## امکانات جدید
ربات: تمدید/ظرفیت/یادداشت/حذف/ریست روی هر کلید، قالب‌های ساخت، «یکی دیگر مثل این»، آنلاین‌ها، رو‌به‌انقضا،
رمز جدید پنل نماینده، پیام به نماینده، ساخت کلید برای نماینده، دامنه‌ی اختصاصی، Panic Lock به‌ازای محصول، پاکسازی.
پنل ادمین/نماینده: فیلتر و جستجوی پیشرفته، عملیات گروهی، QR، مدیریت دستگاه‌ها، سهمیه و دسترسی نمایندگان، لاگ‌ها، بکاپ و Export.
